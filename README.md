# ACLians Fullstack Website

## 📌 Overview

ACLians is a collaborative full-stack MERN web application developed as part of a team project. The platform provides a structured system for managing sessions, users, and features through a modern web interface.

## 🚀 Features

* Fullstack architecture (MongoDB, Express, React/Next.js, Node.js)
* RESTful API with controllers and models
* Authentication & environment-based configuration
* Organized client-server structure
* Scalable and modular backend design

## 🛠️ Tech Stack

* Frontend: Next.js, React, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* Tools: Git, Postman

## 📁 Project Structure

* `client/` → Frontend (Next.js)
* `server/` → Backend (Express API)

## ⚙️ Installation

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/ACLians-Fullstack-Website.git

# Install client dependencies
cd client
npm install

# Install server dependencies
cd ../server
npm install
```

## 🔑 Environment Variables

Create a `.env` file inside `/server`:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

## ▶️ Running the Project

```bash
# Run backend
cd server
npm run dev

# Run frontend
cd client
npm run dev
```
